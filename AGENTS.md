# Lineamientos del Proyecto - Linkiu.io

## Propósito

Este documento establece las directrices generales para el desarrollo del proyecto Linkiu.io.

## Ramas

- **`staging`**: Rama por defecto para pruebas y desarrollo.
- **`apolo`**: Rama principal/producción. Solo se fusiona desde `staging` cuando los cambios están verificados.

## Flujo de Trabajo

1. Desarrollar en `staging`
2. Verificar cambios
3. Fusionar a `apolo` para producción
